# ふりかえりラジオ動画メーカー

音声ファイル、背景画像、BGMを組み合わせて、ポッドキャスト向けの動画を作成するブラウザーアプリです。音声の選択から動画のプレビュー、MP4のダウンロードまでをブラウザー上で行えます。

アプリ本体は `index.html` です。サーバー側のAPIやデータベース、ビルド工程はありません。動画のエンコードにはFFmpeg WebAssemblyを使用します。`package.json` はなく、npmによる依存関係のインストールも不要です。

## 主な機能

- 音声ファイルのドラッグ＆ドロップ、またはファイル選択
- 背景画像の選択、追加、削除
- 背景画像・BGMリストの編集
- オープニングBGMとエンディングBGMの個別設定
- オープニングBGMの開始タイミングと再生時間の設定
- BGMごとのエンディング重ね時間の設定と素材削除
- エンコードの進捗、経過時間の表示と生成キャンセル
- 生成した動画の画面内プレビューとMP4ダウンロード
- ダウンロード用ファイル名の編集
- システム設定に合わせたライト／ダークテーマ
- エンコード完了時のブラウザー通知
- 追加した背景画像、BGM、選択設定のエクスポート／インポート

## 動作要件

- WebAssembly、JavaScript ES Modules、IndexedDBに対応した最新のデスクトップブラウザー
- FFmpeg WebAssemblyを初回読み込みするためのインターネット接続
- 通知を使う場合は、ブラウザーの通知機能と通知許可

ChromeまたはMicrosoft Edgeの最新バージョンを推奨します。ブラウザーやOSの設定によって、動画プレビューの音声再生や通知の表示に差が出ることがあります。

### ファイルを直接開かず、ローカルサーバーから起動する

`index.html` をダブルクリックして `file://` で開くと、ブラウザーのセキュリティ制限により、外部モジュールの読み込みや通知などが利用できない場合があります。開発時は `localhost` のHTTPサーバーから起動してください。

#### VS Codeを使う場合

1. アプリのフォルダーをVS Codeで開きます。
2. Live Server拡張機能を使い、`index.html` をローカルサーバーで開きます。
3. ブラウザーで表示された `http://localhost:...` のURLを開きます。

#### Pythonを使う場合（Windows）

PowerShellでアプリのフォルダーへ移動し、サーバーを起動します。

```powershell
cd "C:\path\to\ふりかえりラジオクリエーター"
py -m http.server 8000 --bind 127.0.0.1
```

ブラウザーで次のURLを開きます。

```text
http://localhost:8000/
```

サーバーを終了するには、PowerShellで `Ctrl+C` を押します。Pythonランタイム自体は必要ですが、追加のPythonパッケージは不要です。

### CDNから読み込むライブラリー

FFmpeg関連のJavaScriptモジュールとWebAssemblyコアは、実行時に `unpkg.com` から読み込まれます。初回起動時に動画エンジンを読み込めない場合は、インターネット接続、プロキシ、ファイアウォールでCDNへのアクセスが妨げられていないか確認してください。

現在使用しているバージョンは次のとおりです。

- `@ffmpeg/ffmpeg` 0.12.10
- `@ffmpeg/util` 0.12.1
- `@ffmpeg/core` 0.12.6

## 基本的な使い方

### 1. 音声を選ぶ

画面上部の音声ファイル欄に音声ファイルをドロップするか、欄をクリックしてファイルを選択します。

一般的なMP3、M4A、WAVなどの音声を使用できます。実際に読み込める形式は、FFmpegがファイルを解析できるかどうかにも依存します。

音声を選択すると、ダウンロード用ファイル名に音声ファイル名が初期値として設定されます。音声ファイル自体は選択中のページ内で使用され、素材ライブラリーには保存されません。

### 2. 背景画像を選ぶ

- プリセットから背景を選びます。プリセットはアプリ内で生成されるグラデーション画像です。
- 「背景を追加」から手持ちの画像を1枚または複数選び、背景の候補に追加できます。
- 追加した画像は背景の選択欄から選べます。
- 「編集」から背景画像リストを開き、追加した画像を削除できます。内蔵プリセットは削除できません。

背景画像は出力時に1280×720の画面に合わせて拡大・切り抜きされます。

### 3. BGMを追加して選ぶ

「BGMを追加」からMP3、M4A、WAV、AAC、OGGなどの音声ファイルを追加します。同じBGM素材をオープニングとエンディングの両方に選択できます。

追加したBGM素材はブラウザー内に保存されます。オープニングとエンディングには、それぞれ別の素材を選択できます。

BGM設定の「編集」から、各BGMのエンディング重ね時間を個別に変更したり、BGMファイルを削除したりできます。削除したBGMはオープニングとエンディングの両方の選択肢から外れます。

#### オープニングBGM

「開始位置」から次の再生方法を選べます。

| モード | 再生方法 |
| --- | --- |
| 音声と同時に重ねる | 音声とBGMを同時に開始します。 |
| BGM先行で重ねる | BGMを先に開始し、「先行秒」で指定した時間が経過した後に音声を開始します。 |
| 音声開始後に重ねる | 音声を先に開始し、「開始後秒」で指定した時間が経過した後にBGMを開始します。 |
| BGM後に音声を開始 | BGMを再生し終えた後に音声を開始します。音声とBGMは重なりません。 |

「再生秒」に `0` を指定すると、BGM素材の全体を再生します。素材の長さより大きな秒数を指定すると、指定時間に達するまでBGMをループします。

「BGM先行で重ねる」では、先行時間がBGMの再生時間より短くなるように設定してください。「音声開始後に重ねる」では、開始後の時間が音声の長さより短くなるようにしてください。設定した時間では音声とBGMが重ならない場合、動画生成時にエラーが表示されます。

開始位置、再生秒、開始時間差は、選択中のBGM素材ごとに保存されます。

#### エンディングBGM

エンディングBGMは、音声の終わりに重ねる秒数を指定します。たとえば「重ねる秒数」が5秒の場合、音声終了の5秒前からBGMが流れます。選択中のBGMは画面上で変更でき、すべてのBGMの設定はBGMリストの「編集」から個別に変更できます。

BGMが音声より長い場合は、音声が終わった後もBGMが続きます。動画と背景は、音声、オープニングBGM、エンディングBGMのうち最後に終わるものに合わせて延長されます。

重ねる秒数は、音声とエンディングBGMの両方の長さより短く設定してください。

### 4. 保存名と通知を設定する

保存名は生成欄で編集できます。初期値は `【音声ファイル名】` です。ファイル名に使えない文字などがある場合は、入力欄にエラーが表示されます。拡張子 `.mp4` はダウンロード時に付与されます。

「エンコード完了時に通知」にチェックすると、ブラウザーの通知許可を確認します。許可すると、動画生成が正常に完了したときに通知が表示されます。通知をクリックするとアプリに戻り、プレビュー位置へ移動します。

通知は任意の機能です。通知を拒否した場合や、ブラウザー／OS側で通知がブロックされている場合は表示されません。拒否済みの場合は、ブラウザーのサイト設定でこのアプリの通知を許可してから、チェックを入れ直してください。通知設定はブラウザーとサイトの組み合わせごとに保存されます。

### 5. 動画を生成する

音声と背景を選び、「動画を生成」を押します。

- 進捗とエンコード経過時間が生成欄に表示されます。
- 生成中はボタンが「生成をキャンセル」に変わります。クリックすると処理を中断できます。
- 正常に完了すると、動画プレビューとMP4のダウンロードリンクが表示されます。
- 通知を有効にしている場合、正常完了後にブラウザー通知も表示されます。

ページを閉じたり再読み込みしたりすると、進行中のエンコードは継続できません。完了するまでアプリのページを開いたままにしてください。

## 出力仕様

現在のエンコード設定は次のとおりです。これらの値を変更する画面設定はありません。

- コンテナ：MP4
- 解像度：1280×720
- フレームレート：30 fps
- 映像：H.264（libx264）、CRF 23、`veryfast` プリセット、`yuv420p`
- 音声：AAC、192 kbps

エンコードはブラウザー内のFFmpeg WebAssemblyで行われます。音声や画像が大きい場合、エンコードに時間がかかったり、ブラウザーのメモリーを多く使用したりすることがあります。

ブラウザーがMP4内のAAC音声をプレビューできない場合、アプリはプレビュー用音声の変換を試みます。互換性に関する注意が表示されても、ダウンロードするMP4の音声形式は変わりません。

## 素材と設定の保存

### ブラウザー内の保存

- 追加した背景画像とBGMファイルはIndexedDBに保存されます。
- 選択中の背景、BGM、オープニング再生方法、テーマ、通知設定などはブラウザーのローカルストレージに保存されます。
- 音声ファイルと生成済みの動画は素材ライブラリーには保存されません。動画は生成後にダウンロードしてください。
- ブラウザーの保存データを消去すると、追加済みの背景画像やBGMも失われることがあります。必要な場合は事前にバックアップを書き出してください。

保存領域はブラウザーのプロファイルとサイトのオリジンごとに分かれています。たとえば、`http://localhost:8000`、`http://127.0.0.1:8000`、`file://`、異なるポート、別ブラウザー、別プロファイルの間では、保存済み素材は共有されません。

### 別のブラウザーへ移行する

1. 元のブラウザーで「素材設定を別のブラウザーへ移行」から「設定を書き出す」を押します。
2. ダウンロードされたJSONファイルを保存します。
3. 移行先のブラウザーで同じアプリを開き、「設定を読み込む」からそのJSONを選択します。
4. 素材が追加され、バックアップに含まれる選択設定も復元されます。

バックアップには、追加した背景画像・BGMのデータと関連設定が含まれます。音声ファイルや生成済み動画は含まれません。読み込みは既存素材を削除せず、素材を追加します。

## プロジェクト構成

```text
.
├── index.html
├── README.md
├── site-icon-500x500.png
├── Podcastサムネイル4　【編集Ⅰ】.png
├── Podcastサムネイル4【編集Ⅱ】.png
├── Podcastサムネイル4【クラウド活用】.png
├── ふりかえりラジオ_エンディング.mp3
└── ふりかえりラジオ_エンディング.wav
```

- `index.html`：アプリ本体。HTML、CSS、JavaScriptを含む単一ページです。
- `README.md`：この説明書です。
- `site-icon-500x500.png`：サイトのファビコンと同じデザインを500×500pxで書き出したPNG画像です。
- 同梱の画像とBGMファイルは例として利用できますが、自動的に素材ライブラリーへ登録されるわけではありません。アプリの「背景を追加」「BGMを追加」から読み込んでください。

## トラブルシューティング

### 動画エンジンを読み込めない

初回エンコード時にはFFmpegのライブラリーをCDNから読み込みます。インターネット接続があること、`unpkg.com` へのアクセスがプロキシやファイアウォールで遮断されていないことを確認し、アプリを再読み込みしてください。

### 音声の長さを読み取れない／動画生成に失敗する

ファイルが破損していないか、ブラウザーで扱える形式かを確認してください。必要に応じて、音声を一般的なMP3、M4A、WAV形式に変換して再度選択してください。

### オープニングやエンディングBGMの設定でエラーになる

指定した時間差や重ねる秒数が、対象の音声またはBGMの長さより短いか確認してください。オープニングBGMの再生秒を `0` にしている場合、その素材の実際の長さが使用されます。

### 通知が届かない

1. アプリ内の「エンコード完了時に通知」にチェックが入っていることを確認します。
2. ブラウザーのサイト設定で通知が許可されていることを確認します。
3. OS側でブラウザー通知が集中モードなどにより抑制されていないか確認します。
4. アプリを別のホスト名やポートで開いていないか確認します。通知許可はオリジンごとに異なります。

通知の許可を拒否した後は、ブラウザーのサイト設定から許可を変更してください。ページを閉じるとエンコード自体も継続できません。

### 追加した素材が別のブラウザーに表示されない

ブラウザー間で素材は自動共有されません。「設定を書き出す」「設定を読み込む」を使って移行してください。また、同じブラウザーでもURLのホスト名やポートが異なると保存領域が分かれます。

### プレビューの音声が再生されない

ブラウザーによっては、MP4内のAAC音声をプレビューできないことがあります。画面に互換性の案内が表示された場合は、ダウンロードしたMP4を別のプレーヤーで確認してください。
